# 🎒 WhatToPack

**WhatToPack** es una aplicación web que te ayuda a planificar de forma inteligente tu equipaje para cualquier viaje. Solo tienes que ingresar tu destino, y el sistema te sugerirá qué empacar según el clima, la duración del viaje y otros factores importantes.

## 🚀 Funcionalidades Principales

- Formulario para ingresar los datos del viaje (destino, fechas, motivo, etc.)
- Recomendaciones automáticas de equipaje basadas en el clima y tipo de viaje.
- Secciones organizadas: ropa, electrónicos, higiene personal, medicina, accesorios y más.
- Selección personalizada de ítems mediante checkboxes.
- Vista resumen con todos los ítems seleccionados.
- Opción de descargar la lista en PDF o enviarla por correo.

## 🛠️ Tecnologías Utilizadas

### 🔧 Backend
- **Spring Boot** – Framework robusto para crear APIs REST.
- **Java 17** – Lenguaje principal del backend.
- **MySQL v8.0** – Base de datos relacional para almacenar usuarios, viajes e ítems.

### 🎨 Frontend
- **React** – Librería para la construcción de interfaces de usuario.
- **Tailwind CSS** – Utilidades CSS modernas para un diseño limpio y responsive.
- **pnpm v10.10.0** – Gestor de paquetes rápido y eficiente para React.

### 🧩 Librerías Adicionales
- **SweetAlert2 v11.22.0** – Alertas personalizadas y modernas para mejorar la experiencia del usuario.

## 📦 Instalación (Modo Desarrollo)

### Requisitos previos
- Java 17
- MySQL 8.0
